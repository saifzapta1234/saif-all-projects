# Saif Ullah — Portfolio (React + Vite)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in /dist

- Project data, jobs, tools and skills live in `src/data.js`.
- To show a featured image on card hover, set a project's `f` field to an image path or URL.
- Styles are in `src/index.css`.
